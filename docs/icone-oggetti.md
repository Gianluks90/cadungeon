# Icone degli oggetti

Un'immagine per **categoria** (alcune con varianti `-a`/`-b` o per tipo) e una per ogni **runa**, in `public/tokens/items/<nome>.svg`. Il campo `icon` di ogni oggetto in `public/items/catalog.json` dice quale usare (percorso senza estensione): per cambiare l'icona di un oggetto basta cambiare quel campo. Se un file manca, la card mostra l'icona di riserva.

Varianti: le `-a`/`-b` sono assegnate per ora in base al tipo di tesoro (`a` per negozio e rame, `b` per argento e oro): è provvisorio. Le varianti `relic`, `relic-light`, `relic-dark` sono per le reliquie. `backpack.svg` (lo zaino dell'interfaccia) non è un oggetto.
